# Telegram-бот учебного расписания

Бот для просмотра учебного расписания, автоматической отправки замен и подписки на календарь. Основное расписание загружается из PDF, ежедневные замены — из DOCX на публичном Яндекс.Диске.

## Возможности

- Выбор группы или преподавателя через кнопки.
- Расписание на сегодня, завтра и указанную дату с учётом замен.
- Основное расписание на неделю для числителя и знаменателя.
- Расписание преподавателя по всем группам, включая назначенные и отменённые пары.
- Автоматическая отправка расписания после появления файла замен. Повторная отправка происходит только при изменении расписания выбранной группы или преподавателя.
- Персональные подписки `.ics` для Apple Calendar, Google Calendar и других календарных приложений.
- Полный и короткий форматы календаря с индивидуальными настройками.
- Поддержка личных чатов, групп и отдельных тем Telegram.
- Подсказки команд в меню Telegram.
- Сохранение настроек, подписок и истории отправок в SQLite.

В личных чатах выбор расписания индивидуален. В группах и темах настройки общие: изменить их может любой участник. Формат календаря сохраняется отдельно для каждого пользователя.

## Команды

| Команда | Назначение |
|---|---|
| `/setup` | Выбор группы или преподавателя |
| `/today` | Расписание на сегодня |
| `/tomorrow` | Расписание на завтра |
| `/date DD.MM.YYYY` | Расписание на указанную дату |
| `/week` | Основное расписание для обеих недель |
| `/autopost_on`, `/autopost_off` | Управление автоотправкой |
| `/calendar` | Личная ссылка для подписки на календарь |
| `/calendar_format short` | Короткие заголовки календаря |
| `/calendar_format full` | Полные заголовки календаря |
| `/calendar_off` | Отзыв личных ссылок текущего чата или темы |
| `/help` | Справка |

Команды `/start`, `/group` и `/groups` также открывают выбор расписания.

## Обновление расписания

Основные PDF проверяются при запуске и затем раз в час. Повторно загружаются и разбираются только изменённые файлы. Проверка замен выполняется каждые 10 минут; интервалы настраиваются.

Автоотправка публикует расписание на завтра после появления соответствующего файла замен, даже если для выбранной группы замен нет. Изменения других групп не вызывают повторную отправку.

Верхняя половина разделённой ячейки PDF соответствует числителю, нижняя — знаменателю. Обозначение `X` означает неназначенного преподавателя: пара сохраняется, но `X` не появляется в списке преподавателей. Сочетания `X / преподаватель` также учитываются.

Противоречащие друг другу замены не применяются произвольно: бот сообщает об ошибке. При сбое обновления сохраняются последние успешно загруженные данные.

## Календарь

Команда `/calendar` создаёт персональную ссылку `.ics`, закреплённую за выбранной группой или преподавателем. Последующая смена выбора в `/setup` не изменяет существующую подписку.

Полный формат включён по умолчанию и содержит сведения о паре. В коротком формате заголовок состоит из фамилии преподавателя, а описание отсутствует. Место проведения сохраняется в обоих форматах: `506б каб.`, `112 каб.`, `спортзал`.

Настройка формата действует на все личные ссылки пользователя. Смена формата не требует повторного подключения календаря.

Расписание на завтра публикуется после обнаружения файла замен и обновляется только при изменении соответствующих событий. Идентификаторы пар сохраняются, отменённые занятия помечаются как отменённые. Подписка содержит события за последние 30 дней, сегодня и завтра; воскресенье пропускается.

Используется **подписка по URL**, а не разовый импорт файла. Частота загрузки обновлений определяется календарным приложением, поэтому изменения могут появляться с задержкой.

Для работы необходимы `CALENDAR_PUBLIC_URL`, домен и HTTPS-прокси к `127.0.0.1:8765` по маршруту `/calendar/`. Порт задаётся через `CALENDAR_PORT`. Без публичного адреса календарная функция отключена.

Ссылки содержат секрет доступа к подписке. Запись полных URL этого маршрута в журналы прокси должна быть отключена.

## Запуск и настройки

Среда выполнения — Python 3.12. Пример подготовки окружения в Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Обязательные параметры `.env`:

| Параметр | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота |
| `NUMERATOR_WEEK_START` | Дата понедельника недели-числителя в формате `YYYY-MM-DD` |

Дата начала числителя должна соответствовать семестру основного расписания. Несоответствие останавливает обновление, чтобы исключить неверное определение недели.

Остальные настройки приведены в `.env.example`: источники файлов, часовой пояс, интервалы проверок, параметры очереди, календарь и журналирование.

Запуск:

```powershell
python main.py
```

Для Ubuntu 24.04 предусмотрен установочный скрипт:

```bash
sudo bash install-ubuntu.sh
```

Скрипт устанавливает зависимости и создаёт службу `schedule-bot` в systemd. Повторный запуск обновляет проект с сохранением конфигурации и данных. Домен, сертификат и прокси для календаря настраиваются отдельно.

## Надёжность и журналирование

Очередь отправки учитывает лимиты Telegram и отдаёт приоритет ответам на команды. Повторные запросы ограничиваются; ошибка одного чата не останавливает остальные отправки. При устойчивой недоступности чата автоотправка для него отключается.

Загружаемые файлы проходят проверку формата и размера. Настройки, база, кэш и журналы исключены из Git.

Клиент Telegram использует IPv4. Сетевые настройки сервера и соединения с Яндекс.Диском остаются прежними. Поддержка системных прокси и проверка TLS-сертификатов сохраняются.

Журнал выводится в консоль и записывается в `data/logs/bot.log` с автоматической ротацией. Уровень задаётся через `LOG_LEVEL`, время записывается в UTC. При ошибках сохраняются тип исключения, файл, функция и номер строки — без текста исключения, исходного кода, локальных переменных и содержимого сообщений. Токены Telegram маскируются.

## Проверки

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python -m ruff check .
python -m bandit -r app
python -m pip_audit -r requirements.txt
```

Дополнительные проверки парсера на исходных PDF включаются через `SCHEDULE_PDF_DIR`. GitHub Actions запускает тесты, Ruff, Bandit и аудит зависимостей; Dependabot проверяет обновления еженедельно.
